# AUTOFABRICADOR

Proyecto experimental de factoría local de software asistida por IA. Repositorio **público** de código fuente, pruebas y documentación seleccionados.

**Estado real (R76–R77):** la suite de referencia R76 funciona de forma acotada (web local/SQLite, demostraciones 2D/3D, integración local de Qwen y compilación Android). **No** está demostrado que sea una fábrica universal autónoma de aplicaciones ni que el APK funcione en un dispositivo Android. R77 es una propuesta de arquitectura, no una versión instalada.

Este repositorio **no es un respaldo completo de C: o D:**. Se omiten modelos GGUF, runtimes y SDK binarios, credenciales, bases de datos, logs operativos, historiales privados y pruebas de aceptación reservadas. Se conservan los originales locales. Los componentes requieren sus dependencias verificadas y no deben arrancar con Windows.

**Licencia:** aún no se ha definido ninguna; repositorio público no equivale automáticamente a software con licencia de reutilización. Para colaborar o redistribuir será necesario concretarla.

Leer el handoff R77 y las evidencias R76 antes de retomar la construcción. Ningún cambio publicado constituye una promoción a ACTIVE.
