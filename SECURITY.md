# Política básica de seguridad

No añadir credenciales, datos personales, claves SSH, secretos de GitHub, bases de datos, historiales privados ni pruebas reservadas al repositorio público.

La publicación R79 se realizó mediante una selección de archivos y filtros heurísticos. Estos filtros no constituyen una auditoría de seguridad exhaustiva. Si se descubre material sensible, revocar las credenciales afectadas y gestionar el incidente antes de seguir publicando.

El código generado por un modelo requiere validación y ejecución aislada. Ningún archivo publicado autoriza modificaciones en BOOT, PROD, MMC ni operaciones privilegiadas sobre otros sistemas.
