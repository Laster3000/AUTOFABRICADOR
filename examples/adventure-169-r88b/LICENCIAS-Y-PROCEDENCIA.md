# Procedencia y uso de recursos

Los sprites, fondos, textos, escenarios, guion y código de este ejemplo fueron creados específicamente para la demostración de AUTOFABRICADOR R88 en esta intervención. No contienen recursos de Monkey Island ni de Indiana Jones.

El juego funciona con funciones estándar de HTML, CSS y JavaScript; no distribuye Godot, Popochiu, Pixelorama ni bibliotecas de terceros.

El script de pruebas de navegador depende de Playwright Core y Chrome **solo en el entorno del desarrollador** y no es requisito del juego portable. Las licencias aplicables a herramientas futuras deben fijarse antes de su incorporación o redistribución.

Los componentes de dirección artística originales deben validarse y recibir autorización expresa antes de su publicación como producto terminado.
