# AUTOFABRICADOR R83F - Robot Workshop 2D

Juego nuevo con cuatro modulos JavaScript generados mediante Qwen 3.5 9B local:
rutas, estado, renderizado y controlador. Abrir game/index.html en Chromium.
No requiere Internet, instalacion, servicios ni claves.

Evidencia: 125/125 pruebas originales con entradas publicas y 128/128
con entradas originales reservadas. Restauracion del ZIP en directorio
limpio en el MISMO PC y repeticion de 128/128 en Chromium sin red.

Este es un resultado acotado a una familia de aplicaciones. No es una
fabrica universal, ni valida un segundo ordenador fisico, y no es ACTIVE.

No se publican modelos GGUF, oraculos reservados, logs, tokens, ni
conversaciones privadas. La licencia de codigo abierto aun no se ha elegido.
