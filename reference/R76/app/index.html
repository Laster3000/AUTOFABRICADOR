05 / VERIFICACIÓN
Alcance del producto

 
Demostrado aquí
Base de datos SQLite con API y sesiones locales, interfaz de inventario, juego Canvas 2D, escena WebGL2 y conexión opcional con modelo Qwen instalado.

 
Limitaciones
Ni APK Android nativa ni instalador Windows universal. Tampoco un compilador que convierta cualquier petición en cualquier aplicación. El contrato de la factoría sigue acotado.

 
Seguridad
Servidor vinculado a 127.0.0.1, autenticación, CSRF, control de versiones y consultas SQL parametrizadas. El código generado en R75 procede de aceptación WASI previa y se ejecuta en Chromium.
